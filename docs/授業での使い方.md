# 授業での使い方

IT System Atlas（OSS版）は、ITシステムの体系・規模・ライフサイクルを見渡すための教材アトラスです。授業では、先生が用意する演習や問いの「調べる先」「見せる図」として使えます。

## 用意するもの
- 生徒・学生が見る端末（PC・タブレット・スマートフォン）とブラウザ
- サイト（次のどちらか）
  - 教員のPCで `npm run dev` を動かし、教室のプロジェクターで見せる
  - `npm run build` で作った `apps/web/out/` を校内のWebサーバーや GitHub Pages に置き、生徒が各自の端末で開く

ログイン・個人情報の入力・外部の計測はありません。

## 使える内容
| 内容 | ページ | 授業での使い方の例 |
|---|---|---|
| システムの種類（161件） | `/systems/` | 調べ学習。名前・別名・説明から検索し、産業・種類・層・開発規模で絞り込める。教材カードには「問い」と学習目標がある |
| 01 世界地図 | `/maps/world/` | 12の領域にどんなシステムがあるかを見渡す |
| 02 企業業務地図 | `/maps/business/` | 注文から決算までの仕事の流れと、ERPがハブになる理由 |
| 03 社会基盤地図 | `/maps/infrastructure/` | 重要インフラ分野とシステムの関係 |
| 04 統合階層地図 | `/maps/architecture/` | アプリから社会基盤まで、システムの積み重なりとつながり |
| 05 規模・リスク地図 | `/maps/scale/` | 開発規模・利用規模・止まったときの影響を比べる |
| 06 ライフサイクル地図 | `/maps/lifecycle/` | 企画から刷新・廃棄までの8段階と、各段階を担う組織 |
| 地図のPDF | `npm run print:pdf` | 印刷して配布・掲示する |

## 授業に合わせて変える
- カードの内容は `data/entries/` の YAML を直します。直したら `npm run verify` で確かめてください。

## 注意
- 演習（シナリオ・比較演習）、授業の構成例、ワークシートなどの授業用教材は、このリポジトリには含みません。
- 掲載内容は概要レベルの教育用情報で、下書き（編集部の確認前）を含みます。授業で使う前に担当の先生が内容を確かめてください。
- 評価軸・規模の区分は、教育用に作った目安です。公的な統一基準ではありません。
